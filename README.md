# Confectionery Management System (ERP)

Система управления кондитерским производством на базе Django.

## 🚀 Основные возможности

### 👥 Ролевая система
- **Администратор/Менеджер**: Полный доступ к управлению складом, заказами, персоналом и финансами.
- **Рабочий**: Доступ к списку назначенных заказов и отчетности о выполненной работе.
- **Оптовик**: Просмотр своих заказов, баланса (долга) и возможность оплаты.
- **Гибкие роли**: Возможность создания индивидуальных ролей с детальной настройкой прав доступа.

### 📦 Складской учет
- **Склад сырья (Ингредиенты)**: Учет приходов, остатков по партиям (FIFO) и автоматическое списание при производстве.
- **Готовый склад (Продукты)**: Учет произведенной продукции и автоматический расчет себестоимости и рекомендуемой цены.
- **Рецепты**: Настройка состава каждого продукта для автоматизации списания сырья.

### 📝 Управление заказами
- Создание и отслеживание статусов заказов (`Новый`, `В производстве`, `Готов`, `Завершён`).
- Назначение рабочих на конкретные заказы.
- Автоматическое обновление баланса оптовика при завершении заказа.

### 💰 Финансы и Смены
- **Смены**: Учет доходов и расходов в рамках каждой рабочей смены.
- **Зарплата (ФОТ)**: Автоматический расчет выплат рабочим при закрытии смены (50% от дохода).
- **Касса**: История всех платежей и финансовых операций.

## 🛠 Технологический стек
- **Backend**: Python 3.x, Django 6.0+
- **Database**: SQLite3
- **Frontend**: HTML5, Vanilla CSS, Django Templates

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий** (или перейдите в папку проекта).
2. **Создайте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   venv\Scripts\activate     # Для Windows
   ```
3. **Установите зависимости**:
   ```bash
   pip install django
   ```
4. **Примените миграции**:
   ```bash
   python manage.py migrate
   ```
5. **Создайте суперпользователя**:
   ```bash
   python manage.py createsuperuser
   ```
6. **Запустите сервер**:
   ```bash
   python manage.py runserver
   ```

Теперь проект доступен по адресу `http://127.0.0.1:8000/`.
